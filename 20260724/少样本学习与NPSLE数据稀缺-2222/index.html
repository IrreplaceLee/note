    少样本学习、迁移学习与 NPSLE 数据稀缺¶

    整理日期：2026-07-24 22:22 关联书籍：《PyTorch 深度学习实战》（第二部分 迁移学习相关）

    本轮学到的核心知识¶

    • 「数据为王」的由来：ImageNet（李飞飞）出现前，模型多从零训练、算法为王但效果有限；ImageNet 证明了大规模数据同样是训练效果的关键。
    • 既然数据这么重要，为什么还要研究少样本？ 因为很多场景的数据稀缺是原理上无法解决的硬约束，不是「努力就能扩充」：
    • 罕见病本身病例总数就少（如系统性红斑狼疮、NPSLE）；
    • 长尾 / 突发场景（新病毒、新欺诈手法）在出现那一刻历史数据必然为零；
    • 标注成本极高、需要专家，且专家之间还会有分歧；
    • 伦理 / 隐私 / 法律限制，数据不允许大规模收集共享。
    • 少样本研究和「扩数据」不是二选一，而是并行互补：能扩就优先扩（数据增强、合成数据、仿真）；扩不动的地方才靠少样本方法兜底。
    • 时代变了：今天的少样本 ≠ ImageNet 时代。关键在于大规模预训练模型：
    • 从前模型从零（from scratch）学，非喂海量数据不可；
    • 现在有预训练模型，已学到通用表征（边缘、纹理、语义），做新任务时只需微调（fine-tune），用少量样本补上领域特有信息。
    • 所以「少样本」是站在「数据为王」肩膀上：先用大数据训通用底座，再用极少领域样本拨到具体任务。
    • 数据边际收益递减：从 1000→10000 张提升明显，从 100 万→1000 万可能只提升一点点但成本翻十倍。有时「让模型更会学」比「喂更多数据」更划算。
    • ImageNet 竞赛现状：ILSVRC 年度赛 2010 年始、2017 年办最后一届（分类错误率已接近/超过人类，挑战性被榨干），之后相关评测转到 Kaggle。但数据集本身仍是主力——ResNet/VGG 等预训练权重多在 ImageNet 上训出，以「预训练权重」形式渗透进几乎每个视觉模型。
    • ⚠️ 上述年份为既有知识回答，网络搜索当时未返回有效来源，正式写作请到 image-net.org 核对。

    我踩过的坑 / 薄弱项¶

    • 困惑：既然数据是关键，为什么不先扩数据而去研究少样本？ 正解：对 NPSLE 这类病，数据稀缺是客观硬约束，扩不动；少样本是唯一出路，且与扩数据并行。
    • 认知升级：少样本能成立的现代前提是「预训练 + 微调」，不是凭空从少量数据学会。

    可运行的代码示例¶

    # ===== 迁移学习的直观入口：加载 ImageNet 预训练模型 =====
# 在 Kaggle Notebook 里直接运行
from torchvision import models

# weights 参数会下载在 ImageNet 上预训练好的权重
# 这就是「别人帮你用大数据训好的通用底座」
resnet = models.resnet18(weights='IMAGENET1K_V1')
resnet.eval()   # 推理模式

print(resnet)   # 打印网络结构，感受一下预训练模型长什么样
# 将来做 NPSLE 时，思路就是：加载这样的预训练模型 → 换掉最后的分类层
#                          → 用少量 NPSLE 数据微调（fine-tune）

    延伸提示¶

    • 和研究方向的联系（核心）：这条正是你研究主线「小样本（few-shot）技术」的思想基础。NPSLE 数据天然稀缺，未来大概率走「预训练 + 迁移学习 + 少样本」的路线。
    • 对应书本：《PyTorch 深度学习实战》第二部分（肺结节检测）会让你体会医学数据稀缺的真实痛点，迁移学习相关内容是这条主线的技术落点。
    • 下一步可关注：迁移学习 / fine-tune 的具体做法（冻结哪些层、换分类头），以及数据增强技术。
