# Sigmoid 激活函数入门

> 整理日期：2026-08-03 13:32
> 关联书籍：《PyTorch 深度学习实战》第 6 章 6.1.3～6.1.5

## 本轮学到的核心知识

- **神经元 = 线性运算 + 激活函数**。书里的公式是 $o = f(w x + b)$：先算加权求和 $wx+b$（一个从负无穷到正无穷的数），再丢进激活函数 $f$。激活函数就是那个"压缩/掰弯"的非线性步骤。

- **激活函数为什么必须有**（书 6.1.5 两条硬性质）：
    - **非线性**：如果没有它，`(w*x+b)` 一层层叠起来，等价于**一个**线性函数，网络再深也白搭。非线性才能逼近复杂函数。
    - **可微**：能对它求导，反向传播才能算梯度。

- **Sigmoid 的公式**：

    $$f(x) = \frac{1}{1 + e^{-x}}$$

    效果一句话：**不管输入是多大或多小的数，输出永远被压进 0～1 之间**。所以它的曲线是个 **S 形**——左边贴着 0，右边贴着 1，中间在 $x=0$ 附近平滑爬升，$f(0)=0.5$。

    | 输入 x | 输出 f(x) |
    |---|---|
    | 很大的正数（+10） | 接近 **1** |
    | 0 | 正好 **0.5** |
    | 很大的负数（−10） | 接近 **0** |

- **Sigmoid 的导数**：

    $$f'(x) = f(x)\,(1 - f(x))$$

    - 好处：用函数值自己就能算出导数，很方便。
    - 图像是个**钟形**：在 $x=0$ 处最大（**0.25**），往两边迅速掉到接近 0。
    - 含义：$x$ 在 **0 附近**时曲线陡 → 输入稍变、输出就明显变（**敏感**）；$x$ 到**两端**时曲线趴平 → 输入变半天输出几乎不动（**迟钝/饱和**）。

- **Sigmoid 用来干嘛**：把加权求和变成一个 **0～1 的"概率式"输出**，最常见于**二分类**（是/不是）。书里点明：Sigmoid 又叫 **logistic 函数**，早期很常用，**现在不常用了，除非明确需要把输出规范到 0～1（比如输出是一个概率）**。

- **现在更常用 ReLU**：书 6.1.4 说 ReLU 是"目前性能最好的通用激活函数之一"。原因和"梯度消失"有关，见下方延伸链接。

## 我踩过的坑 / 薄弱项

- **误区：以为激活函数的输入 `x` 是原始数据。** 其实公式里那个 `x` 是**前一层加权求和 `w*x+b` 算完的结果**，再喂给 Sigmoid。图里"加权求和"这个注释指的就是这一步。

- **误区：不知道"把数压到 0～1"有啥用。** 关键在于 **0～1 可以当概率**。例：判断病人是不是 SLE，网络最后一个数丢进 Sigmoid，吐出 `0.95`＝"95% 可能是"，`0.05`＝"基本不是"，`0.5`＝"拿不准"。

- **误区：把"函数图像"和"导数图像"看混。** 左图（S 形，0→1）是 Sigmoid **本身**；右图（钟形，峰值 0.25）是它的**导数**，描述"在每个点上曲线有多陡"。两张图讲的是两件事。

- **对导数公式发怵。** 其实**现在完全不用会背/会推** $f'(x)=f(x)(1-f(x))$，只要记住"中间最灵、两头发呆、最大 0.25"这个直觉即可。

## 可运行的代码示例

```python
# ============ Sigmoid 激活函数：数值 + 画图 ============
# 可直接整段复制到 Kaggle Notebook 运行
import torch
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['DejaVu Sans']  # Kaggle 无中文字体，标签用英文避免方块
plt.rcParams['axes.unicode_minus'] = False

# 1) 造一串输入 x：从 -10 到 10，取 500 个点
x = torch.linspace(-10, 10, 500)

# 2) Sigmoid 本体：三种等价写法，随便用一种
y = torch.sigmoid(x)              # 官方函数（推荐）
# y = 1 / (1 + torch.exp(-x))     # 按公式手算，结果一样
# y = torch.nn.Sigmoid()(x)       # 大写类的写法

# 3) Sigmoid 的导数：f'(x) = f(x) * (1 - f(x))
dy = y * (1 - y)

# 4) 随便丢几个数进去看效果（体会"压缩到 0~1"）
for v in [-10.0, -2.0, 0.0, 2.0, 10.0]:
    print(f"输入 {v:>6} -> Sigmoid 输出 {torch.sigmoid(torch.tensor(v)):.4f}")
print("导数最大值出现在 x=0：", (y * (1 - y)).max().item(), "≈ 0.25")

# 5) 左右并排画：左=函数(S形)，右=导数(钟形)
fig, axes = plt.subplots(1, 2, figsize=(11, 4))
axes[0].plot(x, y)
axes[0].set_title("Sigmoid  f(x)=1/(1+e^-x)")
axes[0].axhline(0.5, ls='--', c='gray'); axes[0].axvline(0, ls='--', c='gray')
axes[0].grid(alpha=0.3)

axes[1].plot(x, dy, c='orange')
axes[1].set_title("Derivative  f'(x)=f(x)(1-f(x))")
axes[1].axhline(0.25, ls='--', c='gray'); axes[1].axvline(0, ls='--', c='gray')
axes[1].grid(alpha=0.3)
plt.tight_layout(); plt.show()
```

运行后你会看到：左图是从 0 爬到 1 的 S 形，右图是峰值 0.25 的钟形；打印区能直观看到"输入 ±10 → 输出挤到 0 或 1"。
