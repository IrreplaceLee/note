# 图像预处理流水线与张量表示

> 整理日期：2026-07-26 15:35
> 关联书籍：《PyTorch 深度学习实战》第 2 章

## 本轮学到的核心知识

- **`transforms.Compose([...])` 是一条图像处理流水线**：把多个处理步骤串起来，图片进去，一步步加工，最后吐出可喂给网络的张量。
- 书里这条流水线有 4 道工序：
  - **`Resize(256)`**：把图片短边缩到 256 像素（长边按比例缩放），先统一大小。
  - **`CenterCrop(224)`**：从中间抠出 224×224 的方块。为什么必须 224？因为 ResNet 当年在 ImageNet 上训练时输入就是 224×224，**喂它的图必须和它见过的一样大**，否则网络内部维度对不上。
  - **`ToTensor()`**：把 PIL 图片转成 PyTorch 张量，同时做两件事——① 像素值从 `0~255` 整数变成 `0.0~1.0` 浮点数；② 维度顺序从 `(高, 宽, 通道)` 变成 `(通道, 高, 宽)`，即 `(3, 224, 224)`。
  - **`Normalize(mean, std)`**：对 RGB 三通道分别做 `(x - mean) / std`。那两组数字 `[0.485, 0.456, 0.406]` 和 `[0.229, 0.224, 0.225]` 不是随便写的，是 **ImageNet 全体图片算出来的均值和标准差**。
- **核心原则：推理时的预处理必须和训练时一模一样。** 网络"学会"的是处理某种分布的图，你得把自己的图"伪装成 ImageNet 训练集里的一张图"，网络才能给出靠谱预测。
- **什么是张量（Tensor）**：一种 PyTorch 多维数组。一张彩色图 = 3 张灰度图（R、G、B 各一张）叠在一起，每张 224×224，合起来形状 `(3, 224, 224)`，共 `3×224×224 = 150528` 个数字。网络眼里没有猫狗，只有一堆数。

## 为什么是 224 而不是 225

- CNN 里的**下采样**（stride=2 的卷积/池化）每做一次尺寸就除以 2。ResNet 下采样 5 次：`224 → 112 → 56 → 28 → 14 → 7`，**每一步都是整数**。
- 用 225 的话 `225 / 2 = 112.5` 出现小数，计算机得取整，导致边缘不对称、每层要处理取整麻烦。
- `224 = 7 × 2⁵`，倒推自"想让特征图在 5 次减半后干净地停在 7×7"。7×7 是送进全连接层前的黄金落点（太大参数爆炸，太小丢信息）。
- 这个尺寸从 2012 年 AlexNet 沿用至今，成了业界默认约定，方便不同模型互相比较、迁移。

## 我踩过的坑 / 薄弱项

- **误以为"只保留 224×224 会丢掉边缘信息很亏"**。实际是取舍：ImageNet 图片主体多在中央，丢的是无关背景；而"直接缩成 224×224 不裁剪"会让图片**变形**（猫脸压扁），变形对识别的伤害通常比丢边缘更大。
- **训练阶段其实用的是随机裁剪 `RandomCrop` + 随机翻转 `RandomHorizontalFlip`**，网络见过各种位置的主体，对"边缘丢一点"已经免疫；**推理阶段才用 `CenterCrop`**，因为要结果稳定。
- 追求精度时可用 **TTA（测试时数据增强）/ 10-crop**：从四角+中心各裁一块再翻转，共 10 张跑推理取平均，精度略高但慢 10 倍。入门不必纠结。

## 可运行的代码示例

```python
from torchvision import transforms
from PIL import Image

# 定义预处理流水线（书中原例）
preprocess = transforms.Compose([
    transforms.Resize(256),          # 短边缩到 256
    transforms.CenterCrop(224),      # 中间裁 224×224
    transforms.ToTensor(),           # 转张量 + 归到 0~1 + 换维度顺序
    transforms.Normalize(            # 减均值除标准差（ImageNet 统计值）
        mean=[0.485, 0.456, 0.406],
        std=[0.229, 0.224, 0.225]
    )
])

img = Image.open("dog.jpg")          # 打开一张图
img_t = preprocess(img)              # 走完流水线
print(img_t.shape)                   # torch.Size([3, 224, 224])
```
