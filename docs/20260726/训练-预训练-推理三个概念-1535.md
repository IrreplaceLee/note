# 训练、预训练、推理三个概念

> 整理日期：2026-07-26 15:35
> 关联书籍：《PyTorch 深度学习实战》第 2 章

## 本轮学到的核心知识

用「学生备考」打比方，三个概念一次分清：

- **训练（Training）= 学习的过程**
  - 给网络看大量「图片 + 正确答案」，它一遍猜、一遍改自己的参数，直到猜得越来越准。
  - 流程：网络预测 → 对比正确答案 → 算误差 → 调整内部几千万个参数 → 再来一次。
  - 特点：**耗时、耗钱、耗显卡**。ResNet-101 在 ImageNet 上训练要几十上百块 GPU 跑好几天。

- **预训练（Pre-training）= 别人已经帮你训好的那个模型**
  - `models.resnet101(pretrained=True)` 里的 `pretrained=True` 就是「把官方在 ImageNet 上训好的参数直接下载来用」。
  - 相当于别人花大价钱把学生教到能考 90 分，把这个「考得好的大脑」直接给你。
  - 这是**迁移学习**的基础——省时省钱，不用从零训练。

- **推理（Inference）= 用训练好的模型去做预测**，也叫「前向传播 / 预测」
  - 流程：新图片进网络 → 走一遍所有层 → 输出预测（如「90% 是金毛」）。
  - 特点：**快、不改参数**。参数已固定，网络只是「看一眼给答案」。

## 三者关系

```
预训练  →  (可选：微调训练 fine-tune)  →  推理
[别人训好]                          [你用它预测]
```

- 加载预训练模型后直接推理，跳过了自己训练这一步，所以几秒钟就能跑起来。
- 如果预训练模型不完全适合你的任务，可以在它基础上用自己的少量数据**微调（fine-tune）**，比从零训练省太多。

## 我踩过的坑 / 薄弱项

- 容易把「预训练」和「训练」混为一谈。关键区别：**训练是动作（调参数），预训练是结果（已经调好的现成模型）**。
- 以为用模型就得自己先训练一遍。其实入门阶段最常见的姿势是「加载预训练 → 直接推理」或「加载预训练 → 微调」，很少从零训练。

## 可运行的代码示例

```python
from torchvision import models

# pretrained=True: 下载 ImageNet 上训好的参数（约 170 MB，首次会联网下载）
resnet = models.resnet101(pretrained=True)

# 推理前必须切到 eval 模式（关掉 dropout、固定 BN），否则结果不稳定
resnet.eval()

# 之后把预处理好的 batch 喂进去就是「推理」
# out = resnet(batch_t)   # 不改参数，只前向计算
```

> 注：新版 torchvision 里 `pretrained=True` 已改为 `weights=models.ResNet101_Weights.DEFAULT`，但旧写法暂时仍兼容。

## 延伸提示

- 直接关联你的研究主线 **「多模态融合 / 少样本学习」**：NPSLE 医学数据稀缺，几乎不可能从零训练大模型，**「预训练 + 微调」是必经之路**——通常先用大规模自然图像或医学影像预训练，再用你手上少量 SLE 数据微调。
