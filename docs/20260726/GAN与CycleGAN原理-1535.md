# GAN 与 CycleGAN 原理

> 整理日期：2026-07-26 15:35
> 关联书籍：《PyTorch 深度学习实战》第 2 章（马↔斑马示例）

## 本轮学到的核心知识

- **GAN（生成对抗网络）= 两个网络互相较劲**：
  - **生成器（Generator）**：造假货的「画家」，负责生成假图。
  - **判别器（Discriminator）**：打假的「鉴定师」，负责判断「这张图是真是假」。
  - 画家想骗过鉴定师，鉴定师想识破画家，**互相博弈越来越强**，最后画家画出的假图连鉴定师都分不出真假——假图就跟真的一样了。

- **CycleGAN = 能双向翻译（马↔斑马）的 GAN，需要 4 个网络（2 生成器 + 2 判别器）**：

| 角色 | 名字 | 干什么 |
|---|---|---|
| 生成器 A→B | **G_A2B** | 把马变斑马 |
| 生成器 B→A | **G_B2A** | 把斑马变马 |
| 判别器 B | **D_B** | 判断斑马图真假 |
| 判别器 A | **D_A** | 判断马图真假 |

（A=马域，B=斑马域；G=Generator，D=Discriminator）

- **循环一致性（Cycle，名字由来）**：变过去还得能变回来。
  ```
  真马 --G_A2B--> 假斑马 --G_B2A--> 重建的马（应和原图一样）
             |
             D_B（对比真实斑马照片，判断假斑马像不像）
  ```
  下半部分从真斑马开始反着跑一遍：`真斑马 → G_B2A → 假马 → G_A2B → 重建斑马`。

- **判别器旁的「真实照片」**是给判别器当参考答案的：D_B 握着一堆真斑马照练眼力，每次 G_A2B 生成假斑马就判断「像不像真的」。识破 → 生成器改进；没识破 → 生成器进步了。

## CycleGAN 最牛的地方

- 传统 GAN 要「马→斑马」需**成对数据**（同姿势同背景，一张马一张斑马），几乎找不到。
- **CycleGAN 不需要成对数据**：只要给一堆马照片 + 一堆斑马照片（不用配对），靠「变过去再变回来要一样」这个约束自己学会对应关系。
- 这就是为什么要设计「变过去 + 变回来」的循环——**没有成对答案，就用「能不能变回原样」当监督信号**。

## 能干什么

通用的图像风格互转框架，换数据就能做：照片↔油画、夏↔冬、白天↔黑夜、卫星图↔地图等。

## 我踩过的坑 / 薄弱项

- 一开始不理解「为什么要 2 个生成器 + 2 个判别器」。原因：要**双向**翻译，每个方向都得配一套「画家 + 鉴定师」。
- 不清楚图里「真实斑马/真实马的照片」是干嘛的——它们是判别器的训练参考，不是流程的输出。

## 延伸提示

- **对你的研究极有价值**：CycleGAN 这类**无需成对数据**的思路，正契合医学影像「配对样本稀缺」的痛点。例如不同 MRI 序列间的转换、数据增强/域适应（把一家医院的影像风格转成另一家）都可能用到生成式方法。
- GAN 属于生成式模型大家族，后续可延伸到 Diffusion（扩散模型），目前医学影像生成/增强更多用 Diffusion。
