# 张量切片与范围索引（含 shape 读法）

> 整理日期：2026-07-29 00:20
> 关联书籍：《PyTorch 深度学习实战》（第 3 章）

## 本轮学到的核心知识

- **切片语法 `start:stop:step`，左闭右开**。冒号表示「取一段」，`start` 含、`stop` 不含，`step` 是步长（默认 1）。省略就是「到头」：
  - `1:` = 下标 1 到最后；`:4` = 开头到下标 3；`:` = 全部；`0::2` = 从头隔一个取一个。

- **负数下标从右往左数**：`-1` 是最后一个，`-2` 倒数第二。所以 `1:-1` 依然是左闭右开，只是终点用了负下标 → 从下标 1 到「最后一个的前一个」，效果就是**去掉首尾**。这不是新规则，只是「左闭右开 + 负下标」两条叠加。

- **多维切片用逗号分隔各维度** `[行, 列]`。没写的维度默认全取，所以 `points[1:]` 和 `points[1:, :]` 等价。

- **整数「吃掉」维度，切片「保留」维度**（最关键、最容易在 debug 时踩坑）：
  - `points[1:, 0]` —— 列用整数 `0` 索引，列维度消失，结果降成一维 `(2,)`。
  - `points[1:, 0:1]` —— 列用切片 `0:1`（只含下标 0），维度保留，结果还是二维 `(2, 1)`。
  - 两者装的是同一批数，但形状不同。后面做矩阵乘 / 拼接时形状对不上，常常就是这里少了个冒号。

- **`None` = 增加一个长度为 1 的新维度**，等价 `unsqueeze()`。`points[None]` 把 `(3,2)` 变 `(1,3,2)`。用途：模型通常要求输入带 batch 维度，只有一个样本时用它凑出 `batch=1`。

- **shape（形状）怎么读**：括号里几个数字 = 几维，每个数字 = 那一维的长度。
  - `(2, 2)` 二维，2 行 2 列；`(2,)` 一维、2 个数；`(2, 1)` 二维、2 行 1 列。
  - `torch.Size([2, 1])` 和 `(2, 1)` 是同一个东西，前者是 PyTorch 打印出来的样子。
  - `(2,)` 后面那个逗号不能省：Python 里 `(2)` 是数字 2，`(2,)` 才是「只含一个元素的元组」，用来和数字区分。
  - 记忆法：**括号嵌套几层就是几维**。`5`→0 维，`[5,2]`→1 维，`[[5],[2]]`→2 维。

## 我踩过的坑 / 薄弱项

- **误区**：以为 `1:-1` 违反了「左闭右开」。**正解**：规则没变，`-1` 只是「最后一个元素」的负下标写法，右开把它排除掉，看起来就成了「去首尾」。
- **误区**：分不清 `points[1:, 0]`（一维 `(2,)`）和 `points[1:, 0:1]`（二维 `(2,1)`）的区别。**正解**：整数索引降维、切片索引保维，这是最常见的形状不匹配报错来源。
- **薄弱项**：不理解 `(2,)` 里的逗号和 `torch.Size([2])` 是什么意思——其实就是「一维、长度 2」的两种写法。

## 可运行的代码示例

```python
# ===== Kaggle Notebook 可直接运行 =====
import torch

points = torch.tensor([[4.0, 1.0],
                       [5.0, 3.0],
                       [2.0, 1.0]])   # shape (3, 2)

# --- 范围索引 ---
print(points[1:])        # 第2行到最后（列全取）
print(points[1:, :])     # 同上，显式写出所有列
print(points[1:, 0])     # 那些行只取第0列 → 一维 tensor([5., 2.])
print(points[None].shape)# 前面加一维 → torch.Size([1, 3, 2])

# --- 整数降维 vs 切片保维（重点对比）---
print(points[:, 0].shape)    # torch.Size([3])    整数吃掉列维 → 一维
print(points[:, 0:1].shape)  # torch.Size([3, 1]) 切片保留列维 → 二维

# --- 负下标去首尾 ---
x = torch.tensor([10, 20, 30, 40, 50])
print(x[1:-1])           # tensor([20, 30, 40]) 去掉 10 和 50

# --- shape 读法自测 ---
print(torch.tensor(5).shape)          # torch.Size([])   0维
print(torch.tensor([5, 2]).shape)     # torch.Size([2])  1维
print(torch.tensor([[5],[2]]).shape)  # torch.Size([2, 1]) 2维
```
