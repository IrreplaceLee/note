# 张量的类型、设备(GPU)、原地操作与存取

> 整理日期：2026-07-29 00:20
> 关联书籍：《PyTorch 深度学习实战》（第 3 章）

## 本轮学到的核心知识

### 数据类型 dtype
- 张量每个元素都有类型，用 `dtype` 指定 / 查看。常见：
  - `torch.float`（=float32，默认）、`torch.double`（=float64）、`torch.short`（=int16）、`torch.int64`（整数默认）。
- 三种转类型写法，效果一样，**推荐 `.to()`**（最灵活，能同时改类型和设备）：
  - 创建时指定：`torch.ones(10, 2, dtype=torch.double)`
  - 简写方法：`.double()` / `.short()`
  - 通用方法：`.to(torch.double)` / `.to(dtype=torch.short)`
- **类型自动提升**：不同类型相乘，PyTorch 自动向精度更高的一方对齐（`float64 * int16 → float64`）。注意 `float→short` 会把小数截断，`0.xxx` 基本都变 0。

### 设备迁移（CPU / GPU）
- 张量可以放在 CPU 或 GPU（显卡）上。放 GPU 才能用显卡加速，深度学习必备。
- 搬运方式：
  - 创建时：`torch.tensor([...], device='cuda')`
  - 搬过去：`.to(device='cuda')`（返回新张量，原张量还在 CPU）；简写 `.cuda()`
  - 搬回来：`.to(device='cpu')`；简写 `.cpu()`
  - 多卡指定编号：`'cuda:0'`、`'cuda:1'`（`'cuda'` 默认等于 `'cuda:0'`）
- **关键规律**：运算在哪执行，取决于参与运算的张量在哪个设备上；GPU 张量运算结果仍留在 GPU，不会自动回 CPU。要转 NumPy / 画图 / 打印前，得先 `.cpu()`。
- ⚠️ 没有 GPU 时跑 `device='cuda'` 会报错。**Kaggle 要先在右侧设置把加速器切到 GPU**。

### 原地操作（in-place）
- **方法名以下划线 `_` 结尾 = 原地操作：直接改自己，不返回新张量**。
  - `a.zero_()` 把 a 就地清零；`a.add_(1)`、`a.mul_(2)` 同理。
  - 对比不带下划线的 `a.zero()` / `a.add(1)`：返回新张量，a 本身不变。
- 记住这个命名约定，能避免「以为改了其实没改」或反过来的困惑。

### 与 NumPy 互转 / 存取磁盘
- `t.numpy()` 张量转 NumPy；`torch.from_numpy(arr)` NumPy 转张量。CPU 上二者**共享内存**（改一个另一个也变）。
- 存取：`torch.save(t, '路径')` / `torch.load('路径')`，也可配合 `open(..., 'wb'/'rb')` 用文件对象。
- 大数组用 **HDF5**（`h5py`）：好处是能**只读取文件里需要的一小块**（如 `dset[-2:]` 只取最后两行），不必把整个大文件加载进内存。

## 我踩过的坑 / 薄弱项

- **薄弱项**：不清楚 `.to()`、`.cuda()`、`.double()` 之间什么关系。**正解**：`.cuda()`/`.double()` 是特定场景的简写，`.to()` 是通用款，实际项目多用 `.to()`。
- **易错**：以为对 GPU 张量算完能直接 `print` 大量数据或转 NumPy。**正解**：得先 `.cpu()`。
- **易错**：把 `float` 转 `short` 后奇怪值全变 0。**正解**：整数类型会截断小数，属正常。

## 可运行的代码示例

```python
# ===== Kaggle Notebook 可直接运行（GPU 部分需先开启加速器）=====
import torch

# 1) dtype 与转换
x = torch.ones(2, 2, dtype=torch.double)
print(x.dtype)                 # torch.float64
print(x.to(torch.short).dtype) # torch.int16（推荐 .to()）

# 2) 类型自动提升 + 截断
a = torch.rand(3, dtype=torch.double)  # 0~1 小数
b = a.to(torch.short)                  # 小数被截断 → 基本全 0
print((a * b).dtype)                   # torch.float64 向高精度对齐

# 3) 原地操作：下划线结尾直接改自己
m = torch.ones(2, 2)
m.zero_()
print(m)                       # 全 0，m 本身被改掉了

# 4) 与 NumPy 互转（共享内存）
t = torch.ones(3)
arr = t.numpy()
arr[0] = 99
print(t)                       # tensor([99., 1., 1.]) 张量也跟着变

# 5) 设备迁移（有 GPU 时才成功）
if torch.cuda.is_available():
    g = t.to(device='cuda')    # 搬到 GPU
    g = g + 1                   # 在 GPU 上算
    back = g.cpu()             # 搬回 CPU 才好打印/转 numpy
    print(back)
else:
    print("当前没有 GPU，Kaggle 请到右侧设置切换加速器")
```
