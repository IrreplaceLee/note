# 张量的形状与索引：shape、shape[-1] 与负数索引

> 整理日期：2026-08-01 16:14
> 关联书籍：《PyTorch 深度学习实战》

## 本轮学到的核心知识

- **`torch.randint(low, high, size=...)`：生成指定形状的随机整数张量**
  - `torch.randint(1, 10, size=(2, 3))`：造一个 2 行 3 列、每个数是 1~9 随机整数的张量。
  - ⚠️ **含头不含尾**：范围是 `[1, 10)`，最小能取到 1、最大只到 9，**取不到 10**（和 Python 的 `range(1, 10)` 一个道理）。
  - `size=(2, 3)` 用**元组**（带括号）来指定形状：2 行 3 列。

- **f-string：在字符串里塞变量的打印方式**
  - 写法 `f'...{变量}...'`——字符串前面加个 `f`，花括号 `{}` 里的东西会被替换成实际值。
  - 一次可以塞很多个：`f't1: {t1}, shape: {t1.shape}, row: {t1.shape[0]}'`。

- **`t1.shape`：张量的形状**，可以当成一个列表/元组来看，比如 `torch.Size([2, 3])` 就是「2 行 3 列」。
  - `t1.shape[0]` → 第 0 维 = **行数** = 2
  - `t1.shape[1]` → 第 1 维 = **列数** = 3
  - `t1.shape[-1]` → **最后一维** = 3（这里和 `shape[1]` 相同，因为只有两维）

- **负数索引 `-1`：从后往前数第一个（倒数第一个）**
  - Python 通用规则：`[0]` 从前往后数第一个，`[-1]` 从后往前数第一个，`[-2]` 倒数第二个……
  - 所以 `shape[-1]` 永远指「最后一维」。

- **为什么爱用 `shape[-1]` 而不写死 `shape[1]`**
  - 不管张量是几维，`shape[-1]` 都稳稳指向最后一维，不用先去数「到底有几维」。
  - 二维图片 `(高, 宽)`、彩色图 `(通道, 高, 宽)`、一批图 `(批次, 通道, 高, 宽)`——想拿最后一维（宽）时，`shape[-1]` 一招通吃。

## 我踩过的坑 / 薄弱项

- **薄弱项**：不熟悉负数索引。记牢：`-1` 不是「减 1」，而是「倒数第 1 个」。
- **randint 的坑**：`randint(1, 10)` 想当然以为能取到 10，其实最大是 9（含头不含尾）。
- **易混点**：`shape[-1]`（取形状里的最后一维）和 reshape 里的 `-1`（占位、让系统自动算）是**两个完全不同的 -1**，千万别搞混。详见 [张量变形：reshape 与转置](张量变形-reshape与转置-1614.md)。

## 可运行的代码示例

```python
import torch

# 造一个 2 行 3 列、元素为 1~9 随机整数的张量
t1 = torch.randint(1, 10, size=(2, 3))

# 用 f-string 一次打印多种信息
print(f't1:\n{t1}')
print(f'shape(形状): {t1.shape}')               # torch.Size([2, 3])
print(f'shape[0] 行数: {t1.shape[0]}')           # 2
print(f'shape[1] 列数: {t1.shape[1]}')           # 3
print(f'shape[-1] 最后一维: {t1.shape[-1]}')      # 3（与 shape[1] 相同）

# 负数索引的威力：换成一个四维张量（批次, 通道, 高, 宽）
t2 = torch.randint(0, 255, size=(8, 3, 28, 28))
print(t2.shape)          # torch.Size([8, 3, 28, 28])
print(t2.shape[0])       # 8   —— 批次大小
print(t2.shape[-1])      # 28  —— 不用数几维，直接拿最后一维（宽）
print(t2.shape[-2])      # 28  —— 倒数第二维（高）
```

## 延伸提示

- 本篇讲的是「取**形状里的维度**」（`shape[i]`）；如果想取张量里的**具体元素 / 某一行某一列**，那是另一回事，见 [张量索引与取值](../20260725/张量索引与取值-0040.md) 和 [张量切片与范围索引](../20260729/张量切片与范围索引-0020.md)。
- 学会「看」shape 之后，下一步就是「改」shape，见 [张量变形：reshape 与转置](张量变形-reshape与转置-1614.md)。
- **与研究任务的联系**：以后处理 MRI 影像，张量常是 `(批次, 通道, 深度, 高, 宽)` 这种多维结构。养成「先 `print(x.shape)` 看一眼形状」的习惯，能帮你快速判断数据对不对、维度顺序有没有搞错——这是调试影像模型最常用的一招。
