## 本轮学到的核心知识

- **Tensor（张量）= 能装任意多维数字的容器**，说白了就是「多维数组」。名字吓人，本质简单。
- **用「维度」理解它**（维度 = 需要几个坐标才能定位到一个数字）：

  | 维度 | 数学名字 | 生活例子 | 长啥样 |
  |------|---------|---------|--------|
  | 0 维 | 标量 scalar | 一个温度 | `5` |
  | 1 维 | 向量 vector | 一排数 | `[1, 2, 3]` |
  | 2 维 | 矩阵 matrix | Excel 表格 | `[[1,2],[3,4]]` |
  | 3 维+ | 张量 tensor | 彩色图片、视频 | 一堆表格叠起来 |

  在 PyTorch 里，不管几维，**统一都叫 Tensor**。

- **为什么不用普通 Python 列表，而用 Tensor**：
  1. **算得快**——底层是 C/CUDA 写的，对大批数字做运算比 list 快几十上百倍。
  2. **能上 GPU**——可以搬到显卡上算，深度学习动辄百万个数字，没 GPU 跑不动。
- **深度学习里一切都是 Tensor**：输入的图片、模型参数、输出结果，全是 Tensor。
- **两个最常用的查看属性**：
  - `.shape` —— 看形状（每个维度多长），最高频。
  - `.dtype` —— 看里面装的数字类型（如 `torch.int64`）。

## 我踩过的坑 / 薄弱项

- **误区**：被「张量」这个数学名词吓到，以为很高深。
  **正解**：它就是「多维数组 / 装数字的容器」，0 维也是张量，100 维也是张量。
- **薄弱项**：Python 基础较弱，此前不清楚「为什么不用 list 而要用专门的数据结构」。答案是速度 + GPU。

## 可运行的代码示例

```python
# ===== 在 Kaggle Notebook 里直接运行 =====
import torch

# 1) 0 维（一个数）
a = torch.tensor(5)
print(a)                       # tensor(5)

# 2) 1 维（一排数）
b = torch.tensor([1, 2, 3])
print(b)                       # tensor([1, 2, 3])

# 3) 2 维（表格 / 矩阵）
c = torch.tensor([[1, 2, 3],
                  [4, 5, 6]])
print(c)
print("形状 shape：", c.shape)  # torch.Size([2, 3]) → 2 行 3 列
print("类型 dtype：", c.dtype)  # torch.int64

# 4) 快速造一批数字，不用手写
print(torch.zeros(2, 3))       # 全 0
print(torch.ones(2, 3))        # 全 1
print(torch.rand(2, 3))        # 0~1 随机数

# 5) 张量之间可直接做运算（不用写循环）
x = torch.tensor([1, 2, 3])
y = torch.tensor([10, 20, 30])
print(x + y)                   # tensor([11, 22, 33]) 逐个相加
print(x * 2)                   # tensor([2, 4, 6])    每个乘 2
```
