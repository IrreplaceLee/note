# 张量索引：填几个坐标决定取到什么

> 整理日期：2026-07-25 00:40
> 关联书籍：《PyTorch 深度学习实战》（第 3 章）

## 本轮学到的核心知识

- **核心规律：方括号里给几个坐标，就"锁死"几个维度；锁得越多，剩下的越少。**
  以一个三维张量 `img`，形状 `[通道, 高, 宽]` 为例：

  | 写法 | 锁了几维 | 剩几维 | 结果是什么 |
  |------|---------|--------|-----------|
  | `img[0, 2, 3]` | 3 维全锁 | 0 维 | **一个数**（0 维张量） |
  | `img[0, 2]` | 2 维 | 1 维 | 一排数（1 维张量） |
  | `img[0]` | 1 维 | 2 维 | 一张表（2 维张量） |

- **`img[0, 2, 3]` 是一个数，不是数组**。三个坐标全给定，指向唯一一个像素在红色层上的那一个亮度值。

- **它类型上仍是 Tensor**：打印出来是 `tensor(0.7231)` 这种形式，是一个**0 维张量**（`.shape` 为 `torch.Size([])`，空的）。它「装的内容」是一个数，但「类型」还是张量对象。

- **`.item()`：把「只含一个数的张量」变成普通 Python 数字**。以后打印 loss（误差值）时会经常用到。

## 我踩过的坑 / 薄弱项

- **误区**：以为 `img[0, 2, 3]` 是「一个存放红色取值的数组」。
  **正解**：它是**单个数值**（0 维张量），不是数组。数组是在**少填坐标、留下维度没锁**时才出现（如 `img[0]` 是二维表）。
- **正确的部分**：「它存放这个像素红色的取值」这个理解是对的——只是它是「单个数值」而非「数组」。

## 可运行的代码示例

```python
# ===== Kaggle Notebook 可直接运行 =====
import torch
img = torch.rand(3, 4, 5)      # [通道=3, 高=4, 宽=5]

# 填 3 个坐标 → 全锁 → 一个数（标量）
print(img[0, 2, 3])            # 例如 tensor(0.7231)
print(img[0, 2, 3].shape)      # torch.Size([]) 空的 → 0 维

# 填 2 个坐标 → 剩“宽” → 一排数（1 维）
print(img[0, 2])               # tensor([...5 个数...])
print(img[0, 2].shape)         # torch.Size([5])

# 填 1 个坐标 → 剩“高、宽” → 一张表（2 维）
print(img[0].shape)            # torch.Size([4, 5]) 整个红通道

# 用 .item() 把“只含一个数的张量”变成普通 Python float
值 = img[0, 2, 3].item()
print(值, type(值))            # 0.7231... <class 'float'>
```
