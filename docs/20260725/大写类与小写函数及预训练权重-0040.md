# torchvision 里大写「类」与小写「函数」的区别 + 预训练权重

> 整理日期：2026-07-25 00:40
> 关联书籍：《PyTorch 深度学习实战》（第 2 章）

## 本轮学到的核心知识

- **书里那句话的核心**：`torchvision.models` 里，
  - **首字母大写**的名称（`AlexNet`、`ResNet`、`VGG`）是 **Python 类**——相当于「设计图纸」，定义了网络长什么样。
  - **首字母小写**的名称（`alexnet`、`resnet101`、`resnet18`）是**函数**——相当于「帮你办事的助手」，它用**预定义好的层数和单元数**帮你造好网络，并**可选地下载、加载预训练权重**。

- **类（class）vs 实例（instance）——关键 Python 基础**：
  - **类** = 图纸，只有一份（如 `ResNet`）。
  - **实例** = 按图纸造出来的具体成品，可造很多个。
  - **实例化** = 「造」这个动作（加括号，如 `ResNet()` 或调 `resnet101()`）。

- **`models.AlexNet()` vs `models.resnet101(weights='IMAGENET1K_V1')`**：

  | | `models.AlexNet()` | `models.resnet101(weights='IMAGENET1K_V1')` |
  |---|---|---|
  | 大小写 | 大写 → **类** | 小写 → **函数** |
  | 得到什么 | 空白 AlexNet | 装好预训练权重的 ResNet101 |
  | 权重状态 | **随机**（没学过） | **训练好**（ImageNet 上学过，能直接认图） |
  | 层数 | 类的默认结构 | 函数已定死为 101 层 |
  | 能直接识别图片吗 | 不能（要自己从头训练） | **能**（拿来即用） |

- **小写函数返回的是「类的实例」，不是「类」**。`resnet101()` 内部其实就是「拿 `ResNet` 类造一个实例 + 填好参数 + 下载权重」，再把造好的实例交给你。用 `type(resnet)` 会显示 `ResNet`——那是在告诉你「它是按哪张图纸造的」，不代表它本身是图纸。

- **`weights=True` 是过时写法**，新版 torchvision 用明确枚举值：`weights='IMAGENET1K_V1'`（效果同样是加载 ImageNet 预训练权重，但不会有弃用警告）。

## 我踩过的坑 / 薄弱项

- **误区 1**：以为大写 `AlexNet()` 和小写 `resnet101()` 是同一类东西。
  **正解**：大写是类（图纸），小写是函数（替你造好+可下权重的助手）。
- **误区 2**：说「函数返回一个类」。
  **正解**：函数返回的是**类的实例（成品）**，不是类（图纸）本身。图纸只有一份，成品可以造很多个。
- **薄弱项**：Python「类 / 实例 / 实例化」概念不牢——这是后面学 `torch.nn.Module`、自己搭网络的关键基础。

## 可运行的代码示例

```python
# ===== Kaggle Notebook 可直接运行（加载预训练权重需先开 Internet）=====
from torchvision import models

# 小写函数：造一个 101 层 ResNet 并下载装好预训练权重（推荐写法）
resnet = models.resnet101(weights='IMAGENET1K_V1')
resnet.eval()
print(type(resnet))                          # <class '...resnet.ResNet'> ← 按 ResNet 图纸造的实例
print(isinstance(resnet, models.ResNet))     # True  → 它是 ResNet 类的一个实例
print(resnet is models.ResNet)               # False → 它不是那张图纸本身

# 大写类：直接实例化，得到空白网络（权重随机）
alexnet = models.AlexNet()
print(type(alexnet))                         # <class '...alexnet.AlexNet'>
```

## 延伸提示

- **实践结论**：想要「开箱即用、已经会识别图片」的模型，用**小写函数 + `weights=` 参数**（如 `resnet101(weights='IMAGENET1K_V1')`）——这正是**预训练 / 迁移学习**的入口。想从头训练或改造结构，才用大写类得到空白网络。
- **和研究方向的联系（重点）**：将来做 NPSLE 时，因医学数据稀缺，你大概率会用 `resnet...(weights=...)` 这类**加载预训练模型再微调（迁移学习）**，而不是从空白类从头训。这直接呼应「少样本」这条主线——预训练底座是小样本能成立的前提。
